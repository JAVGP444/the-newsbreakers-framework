# Windows / Windows

[Español](#español) · [English](#english)

## Español

1. Instala Python 3.12 (marca PATH), Node.js LTS y Git.
2. Clona el repo y abre `windows/abrir.bat`. Para parar: `windows/detener.bat`.
3. Instalador: ver la sección Windows en el [`README.md`](../README.md) raíz, o el PDF [`docs/install-es.pdf`](../docs/install-es.pdf).

Datos: `%APPDATA%\TheNewsBreakers`.

Idioma de la app: botón **ES | EN** en la cabecera.

---

## English

1. Install Python 3.12 (tick PATH), Node.js LTS and Git.
2. Clone the repo and run `windows/abrir.bat`. To stop: `windows/detener.bat`.
3. Installer: see the Windows section in the root [`README.md`](../README.md), or the PDF [`docs/install-en.pdf`](../docs/install-en.pdf).

Data: `%APPDATA%\TheNewsBreakers`.

App language: **ES | EN** button in the header.
